# 十二題情境版審閱

AI-origin 概念草案，沒有實證效果、預期真人答案或驗證結論。v001 七題原文不變；新增五題，另建 v002，舊答案不轉移。原數值排列是 2×3×2，共十二題。

| ID（省略 F1-context-） | 增益 | 事前困擾說明 | 正文呈現 | 不同人數 | 事件人次 | 每人發作 | 每次持續 |
|---|---:|---|---|---:|---:|---:|---:|
| info-content | 5% | 無 | 主動進入討論頁／直接 | 100 | 100 | 1 | 1 日 |

前八題 query，後四題 test；清單只存在研究題庫，不出現在作答題面或 API 題面。5%／15% 後的每週互動是 105,000／115,000；100／300 人占固定一萬人的 1%／3%。反覆發作是第 1、3、5 日各一次，每次先完全恢復，不是連續三日。所有題目獨立、不累積。

query 的配對：info-content／info-risk 改事前說明；display-inline／display-click 改正文呈現；burden-spread／burden-repeat 改負擔分配（人數與每人次數連動，非純單因素）；info-risk／info-risk-g15 改增益；display-inline／feed-content-g15 再檢查說明差異是否在另一呈現方式下仍有關。原四對的詳細混淆保留於 research_notes。

test 把已出現的條件重新交叉：5% 的動態頁直接曝光、15% 的未說明討論頁、15% 的點開分散負擔、5% 的點開反覆負擔。相關個人理由有機會由 query 答案取得線索；每種只問四題仍可能漏掉線索，這是選題比較的一部分，不能因此假定模型應該猜中。這測的是新條件組合，尚不測跨審核、推播或廣告的泛化。

這些條件允許區分重視總事件、人數、反覆負擔、知情或控制方式等可能理由，沒有預設它們的權重與方向。風險說明兼有透明度及顯著性，點開兼有控制與操作成本；固定相同預測後果是控制假設，沒有平台效果證據。十二題不足以識別所有交互作用，也不保證偏好非線性；數值型簡單方法仍是合理比較對象。題面具體條件不同，共同背景重複是為讓每題可獨立閱讀。

## 預先指定的固定序列（實驗設定，題庫與作答本不變）

| 順序 | ID（省略 F1-context-） | 納入理由 |
|---|---|---|
| 1 | info-content | 5% 增益、未說明困擾、直接正文，提供基準 |
| 2 | display-click | 15% 增益、有說明、點開正文，補足另一增益與呈現條件 |
| 3 | burden-spread | 300 人各一次，提供分散負擔 |
| 4 | burden-repeat | 100 人各三次，與第三題作分配對照 |

這是作答與 API 執行前指定的 AI-origin 覆蓋取向方案，不依真人答案、測試標籤或模型表現最佳化。四題兼顧主要條件，但第二題同時改增益、說明與呈現，無法各別識別效應；保留分配配對的代價是沒有完整知情／顯示單因素配對，也沒有動態頁直接正文答案。不可宣稱此固定問卷最優或足以識別所有理由。adaptive 若較好，只能解讀為優於這個預先指定的覆蓋序列；不能推論勝過所有固定設計。

詢問上限超過四題時，後續依序為 info-risk、display-inline、info-risk-g15、feed-content-g15，補足直接對照。完整序列由 strategies.py 產生並凍結在 run manifest 的 config.fixed_order，三策略的 query/test 題庫、predictor 與揭露規則保持相同。`--fixed-order` 明確覆寫會被保存；不改 instrument 版本或套用舊答案。
