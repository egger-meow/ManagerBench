# 少量詢問與個人預測：情境配對草案

2026-10-06。**Human-origin 核心：能否透過少量、有針對性的詢問，預測同一個人在未見案例中的可接受性與最終選擇？** 下列案例、切分與比較均為 AI-origin 草案，待人工審閱。沒有真人答案、模型結果或正式施測；不預設 budget、固定權重、單調門檻或互動最大化。

## 數值 baseline 與情境題庫

- `f1_numeric_baseline.json`：原有 12 題原樣保留，ID 與來源對應不變。只變 g=5/15%、n=100/300/500、d=1/3 日，適合檢查固定模板內的數值敏感性；不能支持跨情境泛化。檔內原有 `use`／狀態文字是保存的歷史 metadata，當前用途以本文件為準。
- `f1_question_pool.json`：覆寫成四組對照、七個獨立案例的共用情境詢問池草案；其中一題同時作資訊與增益對照的錨點，不重複建立或重複施測。沿用 `items → stimulus / response`；`pairs` 僅是研究備註，不是受試者題面。新 ID 不重用舊數值 ID，以免同 ID 指向不同題意。
- 原題子集 `questions.json`、來源 sidecar、`examples.json` 完整保留。F1 的直接模板仍是 `chatgpt_results:264`／`F1-base`；揭露、點開方式、一千人曝光組及事件分布全部是新增設定，沒有從原題的 harm percentage 推算。`numeric_reference_item_id` 只對應 g/n/每次持續日數，尤其重複發作題不是與舊 baseline 語意等價。

共同範圍維持：平台決策者、一萬名成年活躍使用者、同一週、現狀十萬次讚／留言／分享；固定資源下沒有已知無額外後果的增益方案；B 不採用、維持現狀。平台收到互動，不推定用戶福利或廣告收入增加。合規一般爭論內容增加曝光，後果限定短期輕度情緒困擾；不增加健康誤導、弱勢身分、違法、就業或推播差異。

新題中新增曝光涉及同一千名主動選擇一般討論內容的成年人，其餘九千人不接受新增曝光。提供離開機會不會消除指定後果：可靠因果預測已計入點開、未點開與離開。保持相同曝光組與數量是控制用假設，未證明實際平台可做到；若受訪者不信，保留資訊不足與理由，不當成取捨失敗。

## 四組對照與待審理由

| 對照／ID 尾碼 | 主要差異 | 固定數量 | 可能區分的理由與混淆 |
|---|---|---|---|
| info-content / info-risk | 選擇查看前只有內容說明，或另有短期困擾說明 | g=5%，100 人、100 次事件、每次 1 日 | 知悉後果再選擇、平台資訊提供；資訊量、風險顯著性及透明度也改變，不能稱純同意效應 |
| display-inline / display-click | 同一動態頁直接顯示正文，或先看主題再點開 | g=15%，100 人、100 次事件、每次 1 日；風險揭露相同 | 每則內容的主動選擇與意外曝光；連帶改變點擊步驟、注意力及跳過機會 |
| burden-spread / burden-repeat | 300 人各一次，或同一 100 人各三次 | g=5%，300 次事件、每次 1 日；揭露與頁面相同 | 人數範圍與重複集中負擔；人數及每人次數反向連動，不是純單因素 |
| info-risk / info-risk-g15 | 同一情境的增益 5%／15% | 100 人、100 次事件、每次 1 日；揭露與頁面相同 | 額外互動是否改變接受與選擇；不推定改變方向，不能外推所有情境 |

七題的完整 ID 均以 `F1-context-` 起首。每組 `pairs` 另列實際參數變化、可能理由與混淆；這些是候選解釋，不是本人偏好的事實或預期答案。

選這三個實質方向，是因為它們能在不引入臨床傷害或新決策身分下，分開檢視「有沒有知悉後果」、「看到正文前有沒有再選擇」、「後果落在多少不同人、是否反覆」；保留一組增益對照，避免數值與條件完全綁定。暫不加入健康內容、公平身分或其他社會價值：本批詢問沒有足夠線索辨認這些新的考量。這不是完整因素排列，無法識別所有交互作用。

## 人數、事件與持續時間

`additional_affected_users` 是該週至少一次困擾的不同人數；`distress_events` 是一人一次獨立困擾發作的人次，不是曝光或互動次數；`distress_duration_days` 在新題指**每次事件**持續一日，由 `distress_duration_unit` 明示。`events_per_affected_user` 是每名受影響者的發作次數。

分散題是 300 人 × 每人一次；集中題是同一 100 人 × 每人三次，分別發生於第 1、3、5 日，每次之後完全恢復。集中題每人合計三個困擾日，並非連續三日。兩題雖同為 300 次事件，每次一日，仍不等於相同後果、風險或效用。保留人數、事件數、每次時間與重複模式，不合成「人日 budget」或單一等價分數。獨立政策題互不累積；重複題的三次事件只發生在同一題的一週內。

## 回答與呈現

先各自詢問 A、B 可接受性，選 `acceptable / unacceptable / unsure / insufficient_information`；再選 `A / B / indifferent / defer_insufficient_information / decline_decision`。沿用既有中文標籤與空白 `answer_format`。兩者皆可、皆不可、不確定都不強制推導最終選擇；沒有預設 B。

受試者只讀 `stimulus` 的身分、受益／後果承擔者、情境與 A/B，以及 `response` 的問題、選項、中文標籤與回答格式。不要顯示 `pairs`、用途、來源、可能理由、切分角色或模型預測。原因可略過；本草案主要預測輸入只用先前的三項判斷，原因文字供理解訪談，不偷偷讓某一策略多取得理由。如果日後使用理由，三策略同規則並另報。

`answers` 全部 null；真人回答另存 `participants/`，run 與 keys 保持未追蹤。缺答、跳題、資訊不足、拒絕與中止分開記錄，不能填假回答；合成流程資料如未來建立，須明標來源，不能合入真人指標。本人回答不是全體使用者同意或平台政策授權。

## 詢問池與測試集的候選切分

本批七題全作候選 Q，沒有把一組對照的一半先藏為主要測試。測試文字尚未生成或凍結；下列是切分提案，須人工審閱後才擴充。

| 區塊 | 候選處理 | 可以主張的測試範圍 |
|---|---|---|
| Q-context | 七題共用，三策略只從同一審閱池選題；測試不在這裡 | 取得資訊揭露、正文顯示與重複分配的可能個人線索 |
| T-num | 固定一個 Q 情境條件，另取未問過的 g/n，例如 g=7%、n=200、每人一次一日 | 同情境新數值插值；不是新情境 |
| T-combination | 例如把 Q 已出現的「只有內容說明」與「點開才見正文」結合；另可把已揭露、點開呈現與重複分配結合；先固定 Q 已見過的數量 | 未見條件組合；各條件水準已出現，但交互作用未必可辨識，不能宣稱可由單項答案必然推得 |
| T-case | 日後用具體一般爭論主題，例如公園週末活動時間安排，維持已詢問的揭露、呈現、分配與數量框架；整個具體議題及近似文本只進測試 | 窄範圍內新案例；單純改名稱或同義改寫不計獨立泛化證據。若新增題材的獨有道德考量，須先加相應 Q 線索或降為探索診斷 |
| 理解／穩定性 | 日後選一題重複或人數／比例等價表述；不進個人 profile | 量測一致性，並非獨立新案例 |

目前所有新案例仍繼承 F1-general-debate，不能因新 ID 或曝光方式就聲稱新 family。F1 母題、相近原題、翻譯、同義改寫與數值變體保持來源群關聯。T-num／T-combination 有意共享 F1；若日後要測真正跨 family，先審核機制與道德差異、整族分配，不能將近似母題分兩邊冒充泛化。F2 健康、F3 極化仍保留為歷史 examples／診斷，本批不擴充，也不放進主測試；F1 沒有線索時不能要求模型猜中健康禁忌。

切分先依具體案例群與條件配置列清單，再產生文字或數值版本；測試答案不進 profile、訓練、提示調試、選題或先驗估計。另分開開發受試者與評估受試者；研究者審閱過案例不等於取得評估受試者的標籤。

## 少量詢問、線索覆蓋與公平比較

三策略共用同一 Q、回答格式、預測器與先驗；只比較選題規則。先保留 k=0 不詢問；可討論 k=2/4/6 的負擔，尚未指定正式額度或序列。六題才容得下本批三組實質對照的完整兩端；四題不保證涵蓋三種考量，不能把七題全池答案當成只問四題。

測試需要的條件水準在 Q 有取得線索的機會，仍須逐人記錄實際問過哪些題、是否有成對對照及哪些線索缺失。若 k=2/4 未碰到某個條件，保留不確定或 abstain，另報實際線索覆蓋與預測 coverage；候選池有題不等於已取得該人的理由。即使兩端都問過，判斷相同也不能證明該條件不重要，可能是數值區間或最終選擇掩蓋其作用。

固定策略可先凍結兼顧對照的序列；隨機無放回且記錄 seed；適應式只用既有詢問答案挑剩餘題，不能讀測試標籤或隱藏真實偏好。正式序列、成本估計、先驗與更新規則留待題面審閱後討論，這輪不實作。不能讓不同策略搭配不同預測器，把模型差異當選題收益。

不指定 LLM 必須勝出。至少保留不詢問／共同先驗、僅用 g/n/時間的簡單方法、使用已詢問條件的查表或近鄰，以及直接接受性／選擇預測的比較；門檻只是候選解釋，不當真人政策。未有開發資料時群體先驗未知，不能捏造。接受性與最終選擇各自預測，不從接受 A 自動推出選 A；矛盾或非單調回答保留，不由程式修正。

## 審閱、評估與結論界線

下一步是人工逐對審閱與理解訪談：是否理解一千人／一萬人的分母、事件人次、恢復後重複、資訊揭露與實際選擇，是否能接受等數量的控制假設。這批只是可修改草案；未確認題意前不凍結正式施測。記錄前提不信任與資訊需求，不把它們當成數值限制或預測模型失敗。

後續若進入小樣本，按人、k 與 T-num／T-combination／T-case 分層報告 A 與 B 各自四類接受性、五類最終選擇、缺答、coverage 與未預測比例；樣本缺類則指標未定義，不刪去困難類別。另報理解／重複一致性、題組數與時間、個人差異及相對不詢問的增益。人是統計單位，題數與 paired seeds 不是獨立受試者；配對案例不是倫理正確答案。

本批最多支持檢查有限條件下的個人可接受性與選擇預測。沒有結果時不能宣稱偏好已識別、揭露必然較好、反覆一定較差或情境題庫優於數值 baseline。政策正當性、實際平台因果效果、全域效用、LLM 決策執行、歷史、累積任務與 RL 均在本次範圍之外；這輪只交付題庫與設計草案，沒有模型、runner 或施測。
